# 来源记录：目标、覆盖与下一步

## 目标与范围

输入组合 RTL，执行固定版本 Yosys `0e82bbefe` 的完整默认 `synth -top`，记录源码到最终通用门网表的对应。查询返回有证据的关联区域与边界，支持直接导出；首次建档的索引供后续增量复用。终点包括 techmap、ABC 和后续优化，不能以 coarse 或 `synth -noabc` 替代。

默认保留普通组合层次，显式 `--flatten` 展平。不通过添加 keep 或改变默认 ABC 脚本制造切点。时序来源、memory、generate、循环、函数/任务不在范围；组合 always、普通子模块及已覆盖参数派生受支持。`m1/m1-opt` 仅是开发检查点，旧 M0 已退役。详见[原生流程](native-synth.md)。

独立 `incremental/` 消费来源记录，已实现自动差分、patch、局部综合及拼接；[EQY 时序预检查](../../incremental/sequential.md) 是整份旧网表复用能力，不解除组合局部替换的范围限制。

## 对应关系的含义

默认返回按记录及明确声明的功能证明得到的区域，不保证最小、唯一或独占。合并后可有多条语句共享一门；共同改写可返回多门整体。电气连接用于计算边界，不自动把全部上游扇入作为该语句的来源。

例如 `t = a & b; y = t ^ c;` 中，若终点保留对应切点，第二条可关联 XOR 并以 t、c 为输入；若 ABC 共同改写，就必须使用有依据的门组或标为候选。直连和常量同样是合法结果，空 cell 列表不能直接解释为没有影响。

查询坐标与实例上下文属于归档的输入版本；新旧坐标迁移由增量差分处理。旧区域的功能对应不等于任意修改都能安全接回，完整新版仍需检查所有外部功能和消费者。

## 当前实现与缺口

| 环节 | 已有能力 | 仍需推进 |
|---|---|---|
| 前端与组合过程 | 语句/表达式身份、动作位、分支与临时路由、覆盖/裁剪证据 | 更复杂简化与展开的依赖 |
| 普通层次 | 实例、端口、参数上下文、真实 flatten 复制及实例查询 | 更复杂展开、拼接后保持层次 |
| 优化与 techmap | 合并、替代、删除、部分算术关系与派生对象；opt_share 共享门组、opt_expr 取反/常量前提、wreduce 端口裁剪证据 | 独立 share、其余 opt_expr/控制改写、复杂算术位级来源 |
| ABC | 内部复制/替换/等价/choice/cut/导出钩子，局部及门组证明，功能区域细化 | 后续重写链缺口、复杂函数的有预算分解 |
| 存储 | JSONL 共享数组与差量、流式重放、SQLite/gzip 共享集合与按需查询 | 按实测进一步降低捕获和在线成本 |
| 区域与契约 | 全部边界输出、共享义务、门组闭合、契约并集；独立旧 RTL 区域 SAT 证明 | 共享消费者分化、消失切点、未选直连输出的语义判断 |
| 查询与导出 | 源码/对象反查、完整参数连接、带边界子网表与重读验证 | 每条新增选择规则的独立验收 |

`coverage`、`coverage_gaps` 与 `precision` 分别报告记录覆盖和关联精度。`abc_output_cone_candidate` 等候选不等于精确定位；`abc_internal_cut`、`abc_internal_joint_cut` 和功能区域证明也不能冒充完整因果历史。当前仍保留 `coverage=partial`、`end_to_end_exact=false` 和来源层的 `safe_for_incremental_reuse=false`；具体替换只在本次新版及绑定验证通过后成立。

## 下一步顺序

1. 先处理已复现的边界失败：stress_3000 的等价表达式导致未选直连输出结构不同，需要语义证明与明确回退，不能取消全部输出检查。
2. 根据扩区轨迹减少重复选区、证据整理与 patch 构造，旧设计相关的共享信息尽量在首次建档完成；依赖新版的成本仍算在线时间。
3. 按实际来源断点补 ABC/组合 pass 钩子和功能分区；无法证明时保留候选或拒绝，不以增加事件种类代替精度验收。
4. 扩大案例验证，分别测捕获、建档后处理、在线生成、后验验证与面积。固定 hyp 已成功的结果不能推及任意大电路。

最新测量、阻塞与保留路径集中在[当前状态](../../docs/status.md)。性能协议见[实验文档](../../experiments/docs/comparison.md)。

本轮组合来源补齐已把资源共享、取反吸收、常量替代和位宽裁剪变成独立验收案例，并增加对象级缺口传播。下一批优先用实际失败案例覆盖 `share` 和其余跨对象优化，再连接 ABC 后续网络转换与 dc2/dch 的断点；入口到 fraig 清理的已有复制链无需重复开发。保留完整默认 synth，补齐的只是已声明规则，整体覆盖仍为 partial。

## 独立验收

| 层次 | 要验证什么 |
|---|---|
| 记录一致性 | 生命周期、版本、引用、差量重放及最终网表一致，缺口明确 |
| 来源选择 | 独立预期下应包含/排除的对象、共享关系与精度正确 |
| 子网表导出 | 所选参数、连接、常量及边界完整，重读等价 |
| 本次替换 | 新版局部功能、所有对外输出与消费者、保留区域及整网验证通过 |

导出等价不能替代来源选择；旧区域证明不能替代本次修改验证。`make test` 要求零跳过。具体来源验收见[选择验收](selection-acceptance.md)，ABC 证据见[内部记录](abc-internals.md)和[功能区域](abc-partitions.md)。
