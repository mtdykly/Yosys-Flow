# 来源证据补齐后的单次复测

这是对 [原双后端测量](backend-comparison.md) 中 B 项的后续修复和复测。原结果保留在 `runs/backend-suite-360/`，本轮结果位于 `runs/backend-suite-supported-360/`，没有覆盖或重写旧测量。

## 本轮补齐的能力

| 原因 | 本轮处理 | 保留的限制 |
| --- | --- | --- |
| `candidate_source_associations` | 从归档旧 `frontend.il` 重建源码切割函数，以 miter/SAT 证明所有边界输出相等且有定义；证书随替换计划保存，可重新构造校验 | 保留候选对象、原精度和 `complete_causal_history=false`，没有声称 ABC 内部因果链完整 |
| `output_functions_not_fully_proven` | 较大网表复制/拼接使用结构化布尔 DAG 证书，避免 BDD 展开超限 | 结构不一致表示未证明，不能代替源码对应证明 |
| `connection_consumers_not_fully_bound` | 门选区排除内部常量填充等观察连接，实际跨区消费者仍完整保留；未选中的模块输出必须验证新旧完整函数不变 | 真正发生变化的直连/常量仍需消费者重接，不把相同常量当成同一信号 |
| 边界锚点缺失、连续扩区 | 根据记录的驱动向上扩区、实际使用者向下扩区；合并去重选择集合，避免嵌套契约的深度上限 | 无法安全绑定时退到父模块，不能把整模块回退称为细粒度复用 |
| 未使用别名含 X | 电气检查作用于实际端口和单元引脚，允许废弃调试别名的 X 填充 | 活跃端口、引脚、以及功能证明输出仍需二值有定义 |

没有新增时序、memory、generate、循环或函数/任务的来源支持。没有关闭最终网表等价、全部输出、消费者、极性、单驱动、无环、输入/归档哈希或证据篡改检查。详细证明语义见 [区域契约](../provenance/docs/region-contracts.md)。

## 测量设置

- ANUBIS：`compare_local9`、`control_local2`，保留层次和展平；EPFL：`ctrl`、`router`、`priority`、`adder`、`bar`、`arbiter`，每个沿用原来固定的 local/shared 单运算符修改。未按新结果换案例或修改位置。
- 两后端 × 16 个案例/模式组合 × F、P-module、P-fine，共 96 个预定在线样本；每项只测一次。20 次独立旧建档，同一个 EPFL 旧电路在 local/shared 间共享。单次数据没有方差或稳定均值的含义。
- 每作业 360 秒墙钟上限，不限产物大小。固定 CPU 1 串行测量；同机其他项目占用 CPU 0，因此本轮换核。没有清空操作系统缓存，也不将前后两轮的时间差全部归因于代码修复。
- 新旧源码、工具、Nangate45 typical 库和 Python 实现冻结并校验；回归先完成再测量。开发诊断目录不计入这 96 项，诊断期间发生过实现修改的结果不用于时间结论。
- 时间截止于完整 generic JSON/IL/Verilog 写出。包含选区所需的旧源码功能证明；不包含首次旧建档、生成后的全网表验证及面积映射。面积将每份成功的完整网表统一映射后累加库单元 area，单位 µm²，不是布局布线面积。
- 原记录 = 原生 JSONL + 全部 ABC 证据文件；索引 = SQLite 或 gzip 查询库；归档 = `base-run/` 全部文件，已包含前两项，单位 MiB。索引构建时间是旧建档总时间的子项。

## 结果

仓库完整回归 **377 项通过，零失败、零跳过**。四批冻结实现与工具一致，跨报告 438 项核对通过；这些是检查数，不是独立电路数。

96 个在线测量组合：**88 项成功，8 项 N，0 项 B，0 项 T**。成功项中 F / P-module / P-fine 分别为 32 / 28 / 28。原表去掉重复次数后的 50 个 B 组合中，本轮 50 个通过。

N 均来自 `arbiter` 的旧建档在 360 秒内未完成，索引体积为零；原版全量 F 仍可测试。它不是这次来源规则补齐后的拒绝，也没有被当作成功或从分母删除。成功生成项均完成整体等价和映射面积检查。

`statement_dependency_slice` 是路径名称：`bar` 经过扩区后仍选中了全部旧门；`ctrl` 也几乎没有复用。`router`、`adder_shared` 及展平 `control_local2` 需要模块回退。`priority` 和 `adder_local` 等保留了较明显的旧逻辑。

**本轮所有成功 P-fine 的 generic 生成时间仍长于 F。补齐支持范围没有变成时间收益。** 两后端的面积和最终门数一致；面积变化来自切割、局部优化及统一工艺映射，并不保证每例改善。
