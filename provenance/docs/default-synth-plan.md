# 组合 RTL 到默认 synth 最终网表的来源查询与导出

## 目标与范围

输入原始**组合逻辑 RTL**，执行一次带记录的固定版本 Yosys `0e82bbefe` 完整默认 `synth -top <top>`，保存源码到最终通用门级网表的对应；用户随后按原始语句/表达式查记录，得到关联区域及带边界端口的子网表。记录还应说明区域的全部对外功能、共享使用者、门组完整性和未证明部分，供后续确定替换范围。来源子系统交付原始记录、可复用验证索引和独立审查契约；独立的 `incremental/` 已开始验证明确修改下的局部替换，任意新版 RTL 是否仍满足旧边界必须另验。原版综合对照是独立验收，不是为每次查询重新综合。

终点包含 `techmap`、默认 ABC 和后续优化。coarse、ABC 前或 `synth -noabc` 仅能用于开发检查，不能代替最终验收。流程不添加 `keep`、不更改 ABC 脚本、不暗中 flatten。Liberty 工艺库映射和完整增量综合系统不在来源子系统交付范围。独立 `incremental/` 已实现变化赋值与依赖驱动的自动局部提取、绑定与拼接，保留模块实例后备策略，消费旧来源状态并生成轻量替换计划，不更改来源查询的证明范围。

来源验收目标是：**在声明支持的组合逻辑范围内，提供有依据的源码到最终网表区域对应，明确边界、共享使用者和未证明部分。允许多条语句共同对应一个门组，不要求组内逐门独占归属。** 完整 ABC 历史按实际证明缺口补齐，不以记录所有内部算法为已有层次及增量功能的前置门槛。

本阶段仅考虑组合电路，时序追踪与导出实现已退役。保留组合 `always` 的动作和分支来源；敏感沿、初始化、推导出的锁存器/状态单元必须拒绝。普通组合子模块的层次、数值参数派生及显式 flatten 已接通；memory、generate、循环和函数/任务仍不支持。支持清单见 [native-synth.md](native-synth.md)。

独立的 `incremental seq-baseline/seq-reuse` 提供 [EQY 时序等价预检查](../../incremental/sequential.md)，在声明的时钟/状态条件下直接复用完整旧网表。它不调用原生来源记录器，不解除本阶段的组合检查；无法证明的时序设计仍需全量综合，不能进入局部替换。

## 来源集合的定义

默认集合按已记录转换关系及明确声明的局部功能切点证明生成，不保证是唯一、最小或独占的电路。合并允许多条语句共同关联同一门；拆分允许一条语句关联多个门。保留共享来源及集合外使用者。

电气连接用于计算导出边界，不自动扩张全部上游逻辑。目标如下：

```verilog
assign t = a & b; // A
assign y = t ^ c; // B
```

若两个运算在终点仍各自保留，精确选择 B 应只返回 XOR，把 `t`、`c` 作为边界输入。若发生共同改写，按实际转换证据返回对应集合并报告精度。**当前已用内部切点证明通过这个例子，包括默认 ABC 映射为 NAND→XNOR 的情况。多级逻辑重新结合时，已有部分案例通过独立边界的多门整体证明；组内保持共同来源，不能逐门独占归属。无法证明的仍返回候选。**

直连与常量也属于合法结果。缺少最终绑定不能直接解释为“已消除”或“无影响”；删除/未生成的结论必须另有证据。查询固定本次输入版本和行列坐标，源码编辑后的坐标迁移不属于本阶段。

`run` 默认执行 synth；`m1`（`proc -noopt; opt_merge`）和 `m1-opt`（`proc; opt_expr; opt_clean; opt_merge; opt_clean`）只用于开发。旧 M0 已退役，不再以时序里程碑安排当前工作。

记录器通过普通 Yosys 调用链的实际变换位置捕获事件，显式维护对象 ID、版本、退休和父子步骤。结构快照用于审计，不能单独证明跨对象来源。默认 synth 仍执行其原有所有 pass；纯组合设计中无状态 pass 的执行不等于提供时序支持。

## 精度与覆盖

查询/导出分别报告 `coverage`、`coverage_gaps`、对象 `precision` 和汇总 `association_precision`。组合过程完整动作证据使用 `process_action`，不完整路由回退 `process_signal_candidate`；对象组替换可为 `cell_group_candidate`。连接可使用 `bit_range`。

ABC 原始日志保留真实区域来源并集；查询按保留输出边界收缩为 `abc_output_cone_candidate`，未知映射保留 `abc_region_candidate` 并报告原因。`abc_internal_cut` 使用内部阶段见证、真实映射/复制关系和独立输入的局部函数证明关联。区域或独立边界超过 10 输入时使用 ROBDD，已解除输入数量的硬门槛；复杂区域的符号校验仍受资源预算约束。`abc_internal_joint_cut` 对部分消失切点提供门组整体证明，保留组内共享来源；不能把这些功能对应称为完整因果来源。`internal_rewrite_provenance=false` 表示完整重写历史仍未建立。详见 [abc-internals.md](abc-internals.md)。

当前 `coverage=partial`、`end_to_end_exact=false`、`safe_for_incremental_reuse=false` 继续保留。任何候选都不能计作精确 cell 定位完成；单个对象的粒度也不证明全路径覆盖。

## 接下来的顺序

已有单模块与普通组合层次的来源查询、区域约束、契约合并及自动替换。来源记录继续作为主体，完整契约用于独立审查，在线增量使用引用证据的轻量计划。

1. **将旧设计分析前置，降低在线成本。** 首次建档保存验证索引，后续核对身份后复用来源状态；自动计划不再嵌套完整父契约或重复复制相同证明。用同一 ANUBIS 功能修改案例复测，到整份新版网表写出为止，后验验证另计。继续定位索引加载、选区、边界函数及绑定的真实成本，详见 [对比实验](../../incremental/comparison.md)。
2. **解决实际阻塞与共享依赖。** ANUBIS 展平后的阶段见证缺失、译码器来源候选与消费者义务仍需补齐。共享旧信号在新版需要分化、旧下游常量化失效时，应在局部综合前识别并正确扩区或拒绝；不能因全输出验证存在而放松选区依据。
3. **按失败案例补 ABC 和组合转换证据。** 已有入口到 fraig 清理的复制/删除、dch 等价/choice、映射 cut、单门及门组证明。后续钩子必须说明解决哪个记录或选择断点；没有证明时保留候选。跨对象常量/控制传播、位宽、共享、算术拆分及 ABC 后优化同样按具体案例推进。
4. **扩大可测规模并保持验收。** 已有 12/16/32 输入共享链的局部目标证明；下一步测更复杂函数、符号预算和记录体积，再判断证明分解、SAT 或快照压缩。组合层次已有实例身份和真实端口/展平复制证据；generate、循环、函数展开及更复杂参数依赖仍是独立扩展。`make test` 要求零跳过，来源选择、记录一致性和导出分别验收。

索引不是新的来源证据，轻量计划不授予任意修改的安全替换保证；候选、预算不足和未支持结构继续明确报告。验收依据为对应源码测试及本次运行报告，历史实验目录不作为依赖；性能数据统一见 [对比实验](../../incremental/comparison.md)。

## 三层独立验收

| 层次 | 必须证明 | 证据 |
| --- | --- | --- |
| 转换记录 | 对象生命周期、版本和来源引用自洽，缺口明确 | 重放、检查点、最终 JSON 对照、输入和产物摘要 |
| 来源选择 | 按约定没有漏选或无依据地加入对象 | 独立预期集合、应包含/排除对象、共享关系、精度断言 |
| 子网表导出 | 所选集合的参数、连接、常量和边界正确保留 | 原网表逐项复制、边界检查、Verilog 重读等价 |

导出等价不能代替来源选择。对于可独立定义预期集合 E 的例子，精确验收要求查询集合 R = E，并列出漏选与额外选择。独立原版与插桩版的相同默认 synth 结果必须一致。

已建与待建案例见 [selection-acceptance.md](selection-acceptance.md)。阶段完成要求是在声明并验收的组合 RTL 范围内，最终来源选择、精度报告和导出均通过三层验收；未触发某种复杂变换的测试不能证明其已覆盖。

## 独立实验：区域替换适用性

已新增四通道组合例子，在保留层次和显式展平两种模式中，从基准来源记录生成契约，独立综合显式新版局部 RTL，替换 16 个门并保留其余 136 个门及引脚连接。完整新 RTL 综合只作为全输出 SAT 验证参考，不能用于寻找或复制局部门。实例、局部规范及边界功能由实验明确给定；原线名消失时核对实际边界功能与极性。具体产物和限制见 [incremental/README.md](../../incremental/README.md)。

| 需要的信息 | 现有基础 | 实验需补的判定 |
| --- | --- | --- |
| 区域承担的完整功能 | 来源集合、门组及旧网表输出 | 对应哪些新版行为；共同改写的语句必须一并考虑，来源列表本身不是完整 RTL 功能重建 |
| 输入边界及极性 | 实际电气信号、别名、驱动及部分切点极性证据 | 新 RTL 是否仍能由这些边界实现；新增依赖需扩大区域或拒绝，不能猜测信号同名即同义 |
| 对外输出与使用者 | `boundary` 中原信号和端点 | 逐个消费者指定新版连接，包括共享旧信号拆成不同新信号的情况 |
| 共享旧逻辑 | 共同来源和集合外使用关系 | 明确保留、复制或扩大重综合范围的选择，不能遗漏未修改功能 |
| 未证明关系 | 候选精度和覆盖缺口 | 分别报告信息不足、需扩大区域、证明失败/超时以及具体实验验证成功；不自动提升原查询精度 |

当前实验采用完全定义的二值组合逻辑，保存旧/新 RTL、局部 RTL、边界绑定、局部网表、拼接网表和验证日志。遗漏输出、未经契约扩展的新增依赖、错误位序/极性、组合环和共享输出的部分修改已有拒绝测试。`auto` 比较旧归档与完整新版的前端表示，在单模块或叶模块内寻找赋值变化，沿新版依赖提取完整局部功能，以旧记录确定实际边界；新增输入用有实际驱动证据的计划扩展处理。无法绑定时沿消费者扩区，再尝试整模块及父实例。任意语法的最小区域、共享消费者自动拆分、保持拼接结果的模块层次及替换后的来源归档仍待实现，见 [automatic.md](../../incremental/automatic.md)。

验证对象是**拼接后的整份设计与新版完整默认 synth 的全部可观察输出**，允许两者结构不同。还要核对保留区域、跨边界端点、单驱动及无环约束。导出重读等价、旧设计的局部对应证明和新局部网表自身正确，均不能单独替代这项整体验证。结果只对该版本对、修改和绑定有效，不给旧区域签发通用安全替换结论。

自动入口还提供有预算的叶模块 `miter + sat` 等价预检查。接口与结构上下文不变、全部变化叶输出等价且有定义、上下文满足二值前提时，可直接逐字节复用已验证的旧网表，省去新版综合与拼接。部分证明成功、功能不同或未知时，其余修改继续上述流程；实际拼接的验收要求不变。这不是来源精度或旧契约声明的升级，也没有生成新版源码的完整来源归档。
