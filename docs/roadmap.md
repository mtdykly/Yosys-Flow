# 组合逻辑来源追踪的后续方向

当前目标是组合 RTL 到默认 synth 最终通用门网表的语句查询与导出。入口已经接通，来源仍为部分覆盖；近期工作以 [default-synth-plan.md](default-synth-plan.md) 为准。

1. **同一输出内部的来源精度。** 补充 ABC 内部改写/映射依据，验证多级组合和共享中间表达式。入口到 fraig 的实际复制链、成功合并、dch 等价/choice、AIG 替换、选中 cut、输出门副本和有界单门/多门整体证明已实现；部分等价表达式的因式分解已能关联为共享门组。后续仍需连接重构和清理阶段的因果链，不能将局部功能对应或候选算作全流程精确定位。
2. **组合前端和优化覆盖。** 完善 AST 简化、参数/宏依赖、常量/控制传播、位宽、资源共享和算术拆分。公共记录接口、对象生命周期和父子步骤已有实现，继续在实际变换位置补证据。
3. **组合实例与展开。** 为组合层次、generate、循环/函数展开增加实例身份、参数上下文和端口绑定；输入范围逐项验收后再开放。
4. **规模与可复核性。** 保留完整回归报告，分别检查来源、记录与导出，再测量综合开销、日志大小、索引和查询成本。JSONL 继续作为事实记录，只有测量表明必要时再增加缓存或数据库索引。

来源查询与导出完成后，才考虑 RTL 差分、组合候选区域、局部重综合和拼接证明；这些不属于当前验收条件。共享旧逻辑是否可复用仍需独立等价证明，`safe_for_incremental_reuse=false` 继续保留。
