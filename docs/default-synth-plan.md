# 组合 RTL 到默认 synth 最终网表的来源查询与导出

## 目标与范围

输入原始**组合逻辑 RTL**，正常执行固定版本 Yosys `0e82bbefe` 的完整默认 `synth -top <top>`；用户指定原始语句/表达式后，系统找到其在最终通用门级网表中的来源关联逻辑，直接导出带边界端口的子网表。

终点包含 `techmap`、默认 ABC 和后续优化。coarse、ABC 前或 `synth -noabc` 仅能用于开发检查，不能代替最终验收。流程不添加 `keep`、不更改 ABC 脚本、不暗中 flatten。Liberty 工艺库映射、RTL 差分、局部重综合与网表拼接不在当前范围。

本阶段仅考虑组合电路，时序追踪与导出实现已退役。保留组合 `always` 的动作和分支来源；敏感沿、初始化、推导出的锁存器/状态单元必须拒绝。当前还不支持层次、memory、generate、循环和函数/任务。支持清单见 [native-synth.md](native-synth.md)。

## 来源集合的定义

默认集合按已记录转换关系及明确声明的局部功能切点证明生成，不保证是唯一、最小或独占的电路。合并允许多条语句共同关联同一门；拆分允许一条语句关联多个门。保留共享来源及集合外使用者。

电气连接用于计算导出边界，不自动扩张全部上游逻辑。目标如下：

```verilog
assign t = a & b; // A
assign y = t ^ c; // B
```

若两个运算在终点仍各自保留，精确选择 B 应只返回 XOR，把 `t`、`c` 作为边界输入。若发生共同改写，按实际转换证据返回对应集合并报告精度。**当前已用内部切点证明通过这个例子，包括默认 ABC 映射为 NAND→XNOR 的情况。多级逻辑重新结合时，已有部分案例通过独立边界的多门整体证明；组内保持共同来源，不能逐门独占归属。无法证明的仍返回候选。**

直连与常量也属于合法结果。缺少最终绑定不能直接解释为“已消除”或“无影响”；删除/未生成的结论必须另有证据。查询固定本次输入版本和行列坐标，源码编辑后的坐标迁移不属于本阶段。

## 当前实现与剩余缺口

| 环节 | 已实现 | 剩余验收 |
| --- | --- | --- |
| 入口与终点 | 默认 `synth` 全流程、最终 JSON/RTLIL/Verilog、源码查询及实际导出 | 到达终点不代表所有转换已有来源证明 |
| 前端 | 简化前语句/表达式 ID、行列、clone/生成位置、部分顶层参数派生 | 完整 AST 简化、宏/参数依赖、组合结构展开 |
| 组合过程 | 动作位、分支控制、临时路由、覆盖/裁剪/不可达分支、无状态直连 | 全部组合过程简化语义及精确删除原因 |
| 优化 | 实际合并、目标替代/删除、别名迁移、子归约合并、mux 树裁剪、部分算术模型关系 | 跨对象常量/控制依赖、位宽/共享及复杂算术变换 |
| techmap | 实际派生对象和输出位对应 | 算术内部门的位级来源，不能仅凭输出连接推断 |
| ABC | 固定源码内部钩子、入口到 fraig 的实际复制链与合并绑定、实际 AIG 替换、dch 等价与 choice、Nf 选中 cut、门对象转换与输出副本；单门、多门及部分等价表达式门组证明 | fraig 后续重构/清理的连续因果链、组内逐门来源、尚未证明的共同改写、证明规模扩展 |
| 导出 | 复制所选 cell/连接、常量、参数和边界；共享说明；重读等价 | 每类新增来源规则的独立选择验收 |

`run` 默认执行 synth；`m1`（`proc -noopt; opt_merge`）和 `m1-opt`（`proc; opt_expr; opt_clean; opt_merge; opt_clean`）只用于开发。旧 M0 已退役，不再以时序里程碑安排当前工作。

记录器通过普通 Yosys 调用链的实际变换位置捕获事件，显式维护对象 ID、版本、退休和父子步骤。结构快照用于审计，不能单独证明跨对象来源。默认 synth 仍执行其原有所有 pass；纯组合设计中无状态 pass 的执行不等于提供时序支持。

## 精度与覆盖

查询/导出分别报告 `coverage`、`coverage_gaps`、对象 `precision` 和汇总 `association_precision`。组合过程完整动作证据使用 `process_action`，不完整路由回退 `process_signal_candidate`；对象组替换可为 `cell_group_candidate`。连接可使用 `bit_range`。

ABC 原始日志保留真实区域来源并集；查询按保留输出边界收缩为 `abc_output_cone_candidate`，未知映射保留 `abc_region_candidate` 并报告原因。`abc_internal_cut` 使用内部阶段见证、真实映射/复制关系和独立输入的局部真值表证明关联，当前至多支持 10 个区域输入；`abc_internal_joint_cut` 对部分消失切点提供多门整体证明，保留组内共享来源；不能把这些功能对应称为完整因果来源。`internal_rewrite_provenance=false` 表示完整重写历史仍未建立。详见 [abc-internals.md](abc-internals.md)。

当前 `coverage=partial`、`end_to_end_exact=false`、`safe_for_incremental_reuse=false` 继续保留。任何候选都不能计作精确 cell 定位完成；单个对象的粒度也不证明全路径覆盖。

## 接下来的顺序

1. **继续补全 ABC 内部来源。** AND→XOR 已通过单门切点验收；三层重结合、共享边界和嵌套条件已通过多门整体包含/排除验收。入口 BLIF → strash → AIG → GIA 的实际复制链已接通，并将原表达式根绑定到 `&fraig` 真正采用的合并；部分分配律因式分解及其反相形式已有共享门组验收。输出门复制后再由 Yosys 合并的来源也已保留。下一步补齐 fraig 清理及后续重构、`&dch` 等阶段之间的复制/替代关系，处理尚无已记录等价根或无法证明的共同改写，再扩展证明规模。证据不足继续返回候选；不能把组级证明计作逐门精确定位。
2. **补齐现有组合结构的来源缺口。** 优先处理跨对象常量/控制传播、`opt_muxtree` / `opt_reduce`、位宽/共享、算术拆分和 ABC 后优化。每类变换都要走通查询与导出。
3. **保持完整回归和可复核报告。** `make test` 已保存测试清单、工具/提交身份、实际命令和结果，任何跳过使完整回归失败。后续随来源规则扩展独立预期，分别完善记录、来源选择、导出检查。功能与来源稳定后测量日志大小、综合开销和查询耗时。
4. **按需扩大组合 RTL 范围。** 在前述来源可靠的基础上逐项增加组合层次实例、generate、循环或函数展开，加入实例和参数上下文；不在本轮重新引入状态电路。

## 三层独立验收

| 层次 | 必须证明 | 证据 |
| --- | --- | --- |
| 转换记录 | 对象生命周期、版本和来源引用自洽，缺口明确 | 重放、检查点、最终 JSON 对照、输入和产物摘要 |
| 来源选择 | 按约定没有漏选或无依据地加入对象 | 独立预期集合、应包含/排除对象、共享关系、精度断言 |
| 子网表导出 | 所选集合的参数、连接、常量和边界正确保留 | 原网表逐项复制、边界检查、Verilog 重读等价 |

导出等价不能代替来源选择。对于可独立定义预期集合 E 的例子，精确验收要求查询集合 R = E，并列出漏选与额外选择。独立原版与插桩版的相同默认 synth 结果必须一致。

已建与待建案例见 [selection-acceptance.md](selection-acceptance.md)。阶段完成要求是在声明并验收的组合 RTL 范围内，最终来源选择、精度报告和导出均通过三层验收；未触发某种复杂变换的测试不能证明其已覆盖。
