# 完整组合网表的分层等价验证

`auto` 和显式 `run` 在候选网表生成后，使用同一个验证器比较完整新版全量综合网表与候选网表；Verilog 重读检查也使用它。覆盖全部顶层输出位，内部名字不作为等价假设。验证不参与选区或拼接，不从参考网表复制实现。

当前支持 Yosys JSON 中的普通组合层次及标量 generic 逻辑门，包括反相、AND/OR/XOR、MUX、AOI/OAI。层次只在验证视图中展平。接口的名字、方向、位宽和范围必须一致；时序、初始化、未知单元、重复驱动、未驱动引脚、组合环和实际电气引脚上的 X/Z 均拒绝。无电气作用的调试别名不参与判断。

## 验证顺序

1. **结构函数匹配。** 按顶层输入名和位位置建立共同输入，拓扑遍历两份设计，将门的已知二值语义转换为共享 AND/补边表达式。使用完整元组驻留，哈希碰撞不会构成证明；内部 cell/wire 名字不参与匹配。
2. **有证明的功能对应。** 256 位确定性仿真特征只用于提出内部对应候选。构建候选关系的依赖图，按依赖顺序处理；强连通分量内的对应关系一起展开。只允许把已证明的函数关系或完全相同的结构函数作为切点。小切点使用完整真值表，较宽切点使用有节点和工作量上限的 ROBDD。未知依赖展开原逻辑，不作为假设；证明不了就保留原表达式。对切点关联造成的失败会尝试扩大范围。
3. **逐输出分区 SAT。** 对尚未完成的输出提取差异锥，以已证明的共同函数为独立输入。默认最多 20,000 个 AIG 节点，每次 SAT 最多 5 秒；不超过共享分区预算。抽象切点的反例可能违反实际切点之间的相关性，因此只能触发扩区或回退，不能直接宣布整网不等价。相同证明义务在一次验证中复用。
4. **复用证据的剩余任务求解。** 小分区未完成时，将剩余输出合并为一个多输出任务，相同输出义务去重，共享逻辑只导出一次；已由前一步证明的节点关系已代入两侧表达式。以共同函数作为独立切点，直接生成两份缩减 BLIF 交给 ABC `cec`；SAT 后备同样使用缩减 miter。抽象任务最多使用当时剩余时间的 25%，上限 120 秒。
5. **逐层恢复切点定义。** 抽象反例或未知不能宣布整网不等价；先恢复本轮实际使用的切点定义，保留更上游的共同函数作为新切点，最多尝试四个边界层，每层最多 30 秒，仍受抽象阶段和整体验证共享预算约束。若仍不能证明，再恢复所有切点到真实顶层输入的定义，用 ABC／SAT 验证。这个阶段仍保留已证明的节点代入，不重新加载原始网表、丢弃匹配成果。只有不带抽象切点的反例可以判整网不等价。ABC 退出码为 0 不代表证明成功，必须存在明确的结论；读取错误、超时、无结论都归为未知。

为避免小设计因分区而变慢，两侧合计不超过 5,000 个门、结构检查仍有未完成输出时，会先尝试一次最多 2 秒的完整 SAT 检查；预算同时受剩余总预算的 10% 限制。成功则直接完成，未知才进入内部对应和分区阶段。这条快速路径仍检查原始设计的全部输出。

每次正向结果重新检查两份输入文件的 SHA-256，并要求端口表与同名网络表的位映射和范围一致，避免 Python 与 Yosys 解释成不同电路。匹配证据、每个输出的证明方式、分区规模、扩区记录、工具日志和工具二进制哈希写入独立目录。没有跨运行的隐式证明缓存。新增验证器不修改来源归档或其索引，也不把功能证明升级成完整 ABC 因果历史。

`equiv_make -inames` 能帮助结构及名字都稳定的设计，但不同版本重新经过 ABC 后，同名内部对象可能已不是同一功能。因此本验证器不把全部 `$...` 名称直接作为匹配契约。

## 预算和结果

独立命令 `--timeout` 和自动／显式替换的 `--whole-equivalence-timeout` 默认均为 **1200 秒**，是一次完整网表验证各阶段共享的墙钟预算，不是每个分区各有 1200 秒。`--yosys-timeout` 仅控制前端、局部综合、全量参考生成等工具调用，不再控制整网验证；功能不变预检查和来源证明预算保持独立。Verilog 重读比较是另一次验证，单独计时。

内部对应阶段最多占剩余预算的 60%，同时受 `--matching-budget` 限制，默认 360 秒。先处理不依赖未证明关系的候选分量，依赖受阻的分量延后，避免在许多后继中重复展开同一个困难锥。独立候选处理结束后，在剩余预算内重试受阻分量；重试连续 5 秒无新增证明时退出，单分量工作量上限继续生效。小分区阶段最多占当时剩余预算的 25%，上限 30 秒。剩余任务中 ABC 使用该次尝试剩余时间的 75%，给 SAT 留出预算；恢复定义阶段使用全部尚余总预算。外层进程组超时约束覆盖求解，读取、整理及收尾计入总时间。

| `status` | 含义 | 自动流程能否接受 |
|---|---|---|
| `equivalent` | 全部顶层输出已由结构、已证明对应或求解器覆盖 | 是，继续其余交付检查 |
| `different` | 在原始输入域找到不等价；不是仅有抽象切点反例 | 否 |
| `unknown` | 超时、证明资源不足或求解器未完成 | 否 |
| `invalid` | 输入不支持、接口不匹配、损坏或验证期间被修改 | 否 |

生成时间仍截止于候选 JSON/IL/Verilog 写出。`whole_equivalence_seconds` 与 Verilog 重读属于生成后的验证成本。后验验证失败不会丢掉生成阶段计时，也不会发布 `incremental.v`。

## 只重试验证

已生成候选与参考时，不需要重跑旧建档、新版前端、局部综合或新版全量综合：

```bash
python3 -m incremental verify-netlists \
  --gold runs/edit/replacement/work/new-reference.json \
  --gate runs/edit/replacement/work/candidate.json \
  --top top --yosys /opt/oss-cad-suite/bin/yosys \
  --timeout 1200 --out runs/edit-verification
```

`--out` 必须是新目录。`report.json` 在运行中更新 `stage` 和匹配进度；`functional-matches.jsonl` 保存已证明的对应组。分区的 `.json`、`.ys`、`.log` 和剩余任务脚本都保留。`residual-cut-*` 是共同函数切割后的任务，`residual-cut-expandN-*` 是逐层恢复定义后的任务，`residual-concrete-*` 是恢复实际输入定义后的任务；绑定清单保存原输入文件身份、匹配证据摘要、输出义务和切点身份。报告中的 `residuals` 记录两侧剩余节点数、实际抽象切点数、后端耗时和反例能否作为真实反例。`--abc PATH` 可以指定 ABC，`--abc none` 禁用 ABC 回退；找不到默认 `yosys-abc` 时继续使用 SAT。

这个命令只证明指定的两份网表，不会修改旧失败报告或发布交付文件；旧任务尚未完成的 Verilog 重读、归档重校验等检查不能因此冒充已完成。

## 验收

独立测试覆盖内部改名及重新编号、同名错误逻辑、运算重结合、仿真特征碰撞、循环候选关系、抽象反例扩区、全部输出及位序、层次实例、常量与别名、深图、工具失败、共享预算、进程组终止和输入文件被修改。每一种支持的门语义另用 Yosys 的原始门模型与生成的 AIG 做 SAT 对照；该检查不使用本验证器证明自身。

完整回归命令：

```bash
python3 provenance/tools/run_regression.py --out runs/netlist-equivalence-regression
```

证明资源不足仍可能出现，尤其是大范围算术重写。新增对应方式只有在独立证明成功后才能成为切点；不能为了缩短耗时丢弃输出或把未知改成通过。
