# 组合逻辑来源追踪的后续方向

当前目标是组合 RTL 到默认 synth 最终通用门网表的语句查询与导出。入口已经接通，来源仍为部分覆盖；近期工作以 [default-synth-plan.md](default-synth-plan.md) 为准。

1. **可靠的 ABC 区域对应。** 入口到 fraig 的实际复制链、成功合并、dch 等价/choice、AIG 替换、选中 cut、输出门副本和有界单门/门组证明已实现。以失败用例或验证断点决定下一批清理/转换钩子，同时验收边界、共享使用者和候选回退范围。允许共同改写的门组；完整内部历史和逐门独占归属不作为进入下一阶段的门槛。
2. **可查询的区域约束及契约（首轮已实现）。** 一次带记录的全量 synth 后，`diagnose` 提供诊断，`contract` 交付版本绑定、已记录门组闭合和全部旧边界输出函数；`contract-merge` 合并重叠区域、重算接口并重新验证，支持 `extract --contract`。后续定位和契约操作不启动综合。局部重综合与拼接由独立实验消费契约，旧区域功能证明不代表 RTL 来源完整或修改后可安全替换。详见 [region-contracts.md](region-contracts.md)。
3. **证明规模和记录成本。** 基线工具已覆盖超过 10 个区域输入但局部目标较小的共享链，记录快照、日志、内存及分阶段时间。区域函数及宽边界已采用有预算的 ROBDD，12/16/32 输入共享链的小目标恢复独立选择。下一批测量更复杂函数的符号规模与回退，再决定验证分解或 SAT，以及快照压缩、缓存或索引。预算不足保留未证明状态；每轮保留完整回归报告，分别检查来源、记录与导出。
4. **组合前端和优化覆盖。** 按实际案例完善 AST 简化、参数/宏依赖、常量/控制传播、位宽、资源共享和算术拆分。在实际变换位置补证据，避免仅凭结构观察增加来源。
5. **普通组合层次（首轮已实现）。** 默认保留层次，显式 `--flatten`，增加实例身份、参数上下文、端口绑定及实际展平复制证据；同一模块的两个实例可分别查询、生成契约和导出，可跨实例合并契约。只读电气实例视图经独立整体验证，原始层次网表保持不变。generate、循环/函数展开仍作为后续阶段。范围和验收见 [hierarchy.md](hierarchy.md)。

[局部替换实验](../../incremental/README.md) 已验证四通道设计中一个实例的 16 门区域：旧记录定位、明确的新版局部规范、边界绑定、局部综合、拼接及全输出 SAT 验证。自动 RTL 差分、消费者拆分、通用增量综合和保持层次的拼接仍待实现。实验只对具体新旧版本与端点绑定给出结果，不能将旧区域的功能对应升级为任意修改下的安全替换证明；`safe_for_incremental_reuse=false` 继续保留。
